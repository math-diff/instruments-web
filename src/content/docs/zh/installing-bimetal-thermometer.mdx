双金属温度计的测量误差，大半来自安装环节——插入深度不足、安装点
选择不当、读数视角错误，都会让一块合格的表测出不可信的数。本文按
安装全流程梳理要点。

## 安装位置选择

- 测温点应选在**流动、温度均匀**的介质区段，避开死角、阀门下游
  涡流区与加热元件近旁。
- 管道测温时，探杆插入方向**逆流或与流向正交**，测温端应到达或
  接近管道中心线。
- 避免安装在设备保温层外皮或强振动机体上；机泵附近建议选用
  **充油耐振型**表头。

## 插入深度：误差的第一决定因素

探杆插入介质的有效深度不足时，探杆向外的导热会使示值系统性偏低
（测高温介质时尤其明显）。工程经验值：

- **液体介质**：有效插入深度 ≥ 探杆直径的 15–20 倍；
- **气体介质**：因换热系数低，需更大深度，或加装扩大测温端。

示例：φ8 mm 探杆测液体，插入深度应不小于 120–160 mm。管道直径
不足时，采用**斜插 45°** 或在肘管处顺流安装以获得足够深度。

## 接口与安装形式

| 形式 | 适用场合 |
| --- | --- |
| 螺纹连接（M27×2 常见） | 管道直插，最常用 |
| 活络管接头 | 需要定期抽芯检定的场合 |
| 法兰连接 | 设备接口、需要快开密封的场合 |

安装时用生料带或密封垫保证螺纹密封；拧紧时**用扳手卡住接口六方**，
不可拧转表壳，防止机芯受扭损坏。

## 表盘方向与读数

- **轴向型**（指针与探杆平行）：盘面嵌装、柜内安装；
- **径向型**（指针与探杆垂直）：竖直管道上安装，正对巡检通道。

读数时视线应垂直于表盘；度数介于两刻度线之间时按最近刻度估读。

## 校验与维护

- 双金属温度计为纯机械结构，**无需供电与调试**，投入即可使用；
- 定期校验可用二等标准水银温度计或干体炉比对，常检点为量程的
  25%、50%、75%；
- 示值长期偏移超过精度等级允许值时，整机更换（机芯现场不可调整）；
- 保护套管外壁结垢会增大热响应时间，定期清理即可。

## 常见问题

| 现象 | 可能原因 |
| --- | --- |
| 示值偏低且稳定 | 插入深度不足 / 保护管积垢 |
| 指针抖动无法读数 | 环境振动 —— 更换充油耐振型 |
| 表壳接口处渗漏 | 拧表壳造成接口松动 —— 用扳手卡六方重新密封 |
| 突发不指示 | 机芯损坏或探杆弯曲 —— 整机更换 |
