磁翻板液位计结构坚固、几乎免维护，但安装不当（垂直度、连通阀
操作顺序、密度不匹配）仍会造成卡浮子、读数失真。本文覆盖从
开箱到投用的完整流程。

## 安装前核对

- **密度匹配**：翻板液位计依靠磁性浮子随液面升降，浮子的吃水线
  由介质密度决定。订货时申报的介质密度必须与实际一致——密度变化
  超过 ±0.02 g/cm³ 量级会引入可见误差；
- **连接标准**：旁路筒上下法兰与容器侧壁的上下接口对接，形成
  连通器；法兰标准、压力等级按容器接口核对；
- **长度确认**：旁路筒中心距（法兰中心到法兰中心）按容器液位
  范围订货，不可现场切割。

## 安装步骤

1. **垂直安装**：旁路筒必须**竖直安装**，用水平尺在两个相互垂直
   的方向检查，倾斜会导致浮子贴壁卡阻与标尺读数偏差；
2. **上下连通阀**：旁路筒与容器之间必须各装一只**隔离阀**
   （排污阀装在下阀下游），便于投用与检修；
3. **法兰密封**：按介质与温度选择垫片（耐油石棉/PTFE/金属缠绕垫），
   对称均匀把紧；
4. **翻板面板朝向**：旋转面板使标尺正对巡检通道；
5. **远传模块（选配）**：磁簧开关或 4–20 mA 变送模块按刻度范围
   卡装在旁路筒外侧对应位置，模块内磁簧方向与浮子磁极方向一致。

## 投用与排污操作顺序

正确的阀门操作顺序能避免浮子被冲击损坏：

**投用（容器从空到有压）**：

1. 缓慢开启**上阀**，让介质蒸汽/液体先进入旁路筒平衡压力；
2. 再缓慢开启**下阀**，液体逐渐流入，翻板随液位逐格翻转；
3. 全开后检查法兰密封。

**排污/检修**：

1. 关闭下阀、上阀；
2. 打开排污阀泄压排液；
3. 确认旁路筒内无压后再拆卸。

> 严禁在旁路筒带压时拆卸任何部件。

## 介质适应性

| 介质情况 | 处理建议 |
| --- | --- |
| 常规水、油、溶剂（密度 ≥ 0.65 g/cm³） | 标准型 |
| 强酸强碱等腐蚀介质 | 防腐型（衬四氟/PFA，或哈氏合金筒体） |
| 易结晶、易挂料介质 | 定期排污冲洗；重结晶场合慎用，改雷达 |
| 高温（如饱和蒸汽工况） | 高温型浮子与散热片结构，订货注明温度 |
| 密度不稳定（如混合罐） | 慎用翻板，改雷达等非接触式 |

## 常见故障

| 现象 | 可能原因与处理 |
| --- | --- |
| 某段翻板不翻转 | 浮子卡阻：排污冲洗；或该段面板磁柱退磁：更换面板 |
| 就地读数与实际液位偏差固定值 | 介质密度与订货不符：重新标定零位/量程或换浮子 |
| 读数随温度明显变化 | 密度随温度变化——属原理性现象，按工况温度订货 |
| 远传信号跳变 | 模块与浮子磁极方向不符，翻转模块重新卡装 |
| 翻板全部不动作 | 上下阀未开、筒内无液；或浮子磁极装反 |
